# JavaScript ES6+ 核心特性：Set / Map / WeakSet / WeakMap 详解

---

## 一、Set（集合）

### 基本概念
`Set` 是一组**唯一值**的集合，值可以是任意类型（原始值或对象引用），**不允许重复**。

```javascript
const s = new Set([1, 2, 2, 3, 3, 3]);
console.log(s); // Set(3) { 1, 2, 3 }
```

### 常用 API
| 方法/属性 | 作用 |
|---|---|
| `add(value)` | 添加值，返回 Set 本身（可链式调用） |
| `delete(value)` | 删除值，返回 boolean |
| `has(value)` | 判断是否存在，返回 boolean |
| `clear()` | 清空所有元素 |
| `size` | 元素个数（属性，不是方法） |
| `keys()` / `values()` / `entries()` | 遍历器；Set 没有键，`keys()` 与 `values()` 行为一致 |
| `forEach(callback)` | 遍历 |

### 特点
- **成员唯一**：内部使用类似 `===` 的比较（但 `NaN` 在 Set 中被视为等于自身，这是与 `===` 的区别）。
- **可迭代**：可以用 `for...of` 直接遍历。
- 插入顺序即遍历顺序。

### 典型应用场景
1. **数组去重**
   ```javascript
   const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]
   ```
2. **并集 / 交集 / 差集**
   ```javascript
   const a = new Set([1, 2, 3]);
   const b = new Set([2, 3, 4]);
   const union = new Set([...a, ...b]);           // {1,2,3,4}
   const intersect = new Set([...a].filter(x => b.has(x))); // {2,3}
   const diff = new Set([...a].filter(x => !b.has(x)));     // {1}
   ```
3. **标签 / 状态标记集合**：如用户权限集合 `new Set(['read', 'write'])`。

## 二、Map（字典）

### 基本概念
`Map` 是**键值对**的集合，类似于对象，但键可以是**任意类型**（对象、函数、原始值），而不仅仅是字符串/Symbol。

```javascript
const m = new Map();
const objKey = { id: 1 };
m.set(objKey, 'value associated with object');
m.set('name', 'Alice');
console.log(m.get(objKey)); // "value associated with object"
```

### 常用 API
| 方法/属性 | 作用 |
|---|---|
| `set(key, value)` | 设置键值对，返回 Map 本身 |
| `get(key)` | 取值，不存在返回 `undefined` |
| `has(key)` | 判断键是否存在 |
| `delete(key)` | 删除 |
| `clear()` | 清空 |
| `size` | 键值对数量 |
| `keys()` / `values()` / `entries()` | 遍历器 |
| `forEach(callback)` | 遍历 |

### 与普通 Object 的区别
| 对比项 | Object | Map |
|---|---|---|
| 键类型 | 只能是 String / Symbol | 任意类型 |
| 键顺序 | 不保证（现代引擎虽有一定规则，但不可靠） | 按插入顺序 |
| 大小获取 | 需手动 `Object.keys(obj).length` | 直接 `map.size` |
| 遍历 | 需先获取键再遍历 | 原生可迭代，`for...of` 直接用 |
| 原型污染风险 | 有（`__proto__` 等） | 无 |
| 频繁增删性能 | 一般 | 针对频繁增删做了优化 |

### 典型应用场景
1. **需要对象作为键**：如缓存 DOM 节点对应的元数据。
2. **需要保证插入顺序的字典**。
3. **频繁增删键值对**的场景，性能优于普通对象。
4. **需要快速获取大小**的集合。

## 三、WeakSet（弱集合）

### 基本概念
`WeakSet` 与 Set 类似，但有三个关键限制：

1. **成员只能是对象**（不能是原始值）。
2. **对对象的引用是"弱引用"**：如果对象在外部没有其他强引用，垃圾回收器（GC）可以随时回收它，WeakSet 不会阻止回收。
3. **不可遍历、没有 `size`、没有 `clear()`**：因为成员可能随时被 GC，无法保证遍历过程中元素稳定存在。

```javascript
const ws = new WeakSet();
const obj = { a: 1 };
ws.add(obj);
ws.has(obj); // true
// ws.size;        // undefined（不存在）
// ws.forEach(...) // 不存在
```

### 为什么叫"Weak"
普通 Set 持有对象的强引用，即使外部 `obj = null`，Set 内部仍然引用着，对象不会被回收，可能造成内存泄漏。WeakSet 持有的是弱引用，外部引用消失后，对象可被正常回收。

### 典型应用场景
1. **标记对象是否被处理过 / 是否属于某类**，而不影响其生命周期。
   ```javascript
   const processed = new WeakSet();
   function process(node) {
     if (processed.has(node)) return;
     processed.add(node);
     // ...处理逻辑
   }
   ```
2. **避免内存泄漏的对象集合**：如存储 DOM 节点，节点被移除后自动从 WeakSet 中消失。
3. **私有属性的一种实现思路**（但更常用 WeakMap）。

---

## 四、WeakMap（弱字典）

### 基本概念
`WeakMap` 与 Map 类似，但：

1. **键只能是对象**（值可以是任意类型）。
2. **键是弱引用**：键对象在外部没有其他强引用时，会被 GC 回收，对应的键值对也自动消失。
3. **不可遍历、没有 `size`、没有 `clear()`**。

```javascript
const wm = new WeakMap();
const key = { id: 1 };
wm.set(key, 'some metadata');
wm.get(key); // "some metadata"
```

### 典型应用场景
1. **存储对象的私有数据 / 元数据**（最经典用法）
   ```javascript
   const privateData = new WeakMap();
   class Counter {
     constructor() {
       privateData.set(this, { count: 0 });
     }
     increment() {
       const data = privateData.get(this);
       data.count++;
       return data.count;
     }
   }
   ```
   实例被销毁时，对应私有数据自动回收，无需手动清理。

2. **缓存与对象关联的计算结果**：如以 DOM 元素为键缓存计算值，元素移除后缓存自动释放。

3. **避免内存泄漏的事件监听数据 / 监听器存储**。

---


## 五、补充：Weak 系列的内存原理

JavaScript 的 GC 采用**引用计数 + 标记清除**。普通集合持有对象的强引用，会让对象的引用计数 +1，导致无法回收。而 `WeakSet` / `WeakMap` 内部的引用不计入引用计数，当对象仅剩 Weak 引用时，GC 会直接回收它，并把它从 Weak 集合中移除。

这也是为什么 Weak 系列**不能遍历**——遍历过程中某个元素可能正好被 GC 回收，导致遍历结果不确定，所以规范直接禁止了遍历能力。


## 面试总结

Set,Map,WeakMap,WeakSet都是ES6新添加的数据结构,它们都属于JavaScript中的引用类型本质都为Object对象,用来弥补基本类型和引用类型在某些场景不适合应用的问题。

Set是一组唯一值的集合，值可以是任意类型（原始值或对象引用），不允许重复。

Map 是键值对的集合，类似于对象，但键和值都可以是任意类型（对象、函数、原始值），而不仅仅是字符串 / Symbol。

WeakSet与Set类似，但成员只能为对象，对对象的引用是 "弱引用"：如果对象在外部没有其他强引用，垃圾回收器（GC）可以随时回收它，WeakSet 不会阻止回收。

WeakMap与Map类似，但键只能是对象(值可以是任意类型),键是弱引用,键对象在外部没有其他强引用时，会被 GC 回收，对应的键值对也自动消失。不可以遍历，没有size,没有clear()。
