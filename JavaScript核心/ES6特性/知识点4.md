# JavaScript ES6+ 核心知识点详解：Proxy 与 Object.defineProperty

---

## 二、Object.defineProperty 详解

### 2.1 基本用法

`Object.defineProperty` 是 ES5 引入的 API，用于**直接在对象上定义一个新属性，或修改对象的现有属性**，并返回该对象。

```javascript
const obj = {};
let value = 0;

Object.defineProperty(obj, 'count', {
  // 数据描述符
  value: 100,           // 属性值
  writable: true,       // 是否可写
  enumerable: true,     // 是否可枚举（for...in / Object.keys）
  configurable: true,   // 是否可配置（删除/修改描述符）
  
  // 存取描述符（与 value/writable 互斥）
  get() {
    console.log('读取 count');
    return value;
  },
  set(newVal) {
    console.log(`设置 count = ${newVal}`);
    value = newVal;
  }
});
```

### 2.2 数据劫持实现（Vue2 响应式核心）

```javascript
function defineReactive(obj, key, val) {
  Object.defineProperty(obj, key, {
    enumerable: true,
    configurable: true,
    get() {
      // 依赖收集
      track(obj, key);
      return val;
    },
    set(newVal) {
      if (newVal === val) return;
      val = newVal;
      // 触发更新
      trigger(obj, key);
    }
  });
}

// 遍历对象所有属性进行劫持
function observe(obj) {
  if (typeof obj !== 'object' || obj === null) return;
  Object.keys(obj).forEach(key => {
    defineReactive(obj, key, obj[key]);
    observe(obj[key]); // 递归深层对象
  });
}
```

### 2.3 局限性

1. **只能劫持对象的单个属性**：需要遍历每个属性，性能开销大
2. **无法监听新增/删除属性**：Vue2 需要 `Vue.set()` / `Vue.delete()` 补丁
3. **无法监听数组索引变化**：Vue2 重写了数组的 7 个方法（push/pop/shift/unshift/splice/sort/reverse）
4. **无法监听 `length` 属性变化**
5. **深层嵌套需要递归遍历**，初始化性能差
6. **对 `Map`、`Set` 等数据结构无能为力**

## 三、Proxy 详解

### 3.1 基本概念

`Proxy` 是 ES6 引入的**元编程** API，用于创建一个对象的代理，从而实现**基本操作的拦截和自定义**（如属性查找、赋值、枚举、函数调用等）。

> Proxy 是在目标对象之前架设一层"拦截"，外界对该对象的访问都必须先通过这层拦截。

### 3.2 基本语法

```javascript
const proxy = new Proxy(target, handler);
```

- `target`：被代理的目标对象（可以是任何类型的对象，包括数组、函数等）
- `handler`：一个对象，其属性是一些可选的方法，用于定义代理在执行各种操作时的行为

### 3.3 常用拦截器（trap）

```javascript
const handler = {
  // 读取属性
  get(target, key, receiver) {
    console.log(`读取属性: ${key}`);
    return Reflect.get(target, key, receiver);
  },
  
  // 设置属性
  set(target, key, value, receiver) {
    console.log(`设置属性: ${key} = ${value}`);
    return Reflect.set(target, key, value, receiver);
  },
  
  // 删除属性
  deleteProperty(target, key) {
    console.log(`删除属性: ${key}`);
    return Reflect.deleteProperty(target, key);
  },
  
  // 拦截 in 操作符
  has(target, key) {
    return key in target;
  },
  
  // 拦截 Object.keys() / for...in
  ownKeys(target) {
    return Reflect.ownKeys(target);
  },
  
  // 拦截函数调用
  apply(target, thisArg, args) {
    return target.apply(thisArg, args);
  },
  
  // 拦截 new 操作符
  construct(target, args) {
    return new target(...args);
  }
};
```

### 3.4 完整示例：响应式数据

```javascript
function reactive(target) {
  if (typeof target !== 'object' || target === null) {
    return target;
  }
  
  return new Proxy(target, {
    get(obj, key) {
      console.log(`[GET] ${key}`);
      const result = obj[key];
      // 懒递归：只有访问到深层属性时才代理
      return typeof result === 'object' ? reactive(result) : result;
    },
    set(obj, key, value) {
      console.log(`[SET] ${key} = ${value}`);
      obj[key] = value;
      return true; // 必须返回 true 表示设置成功
    },
    deleteProperty(obj, key) {
      console.log(`[DELETE] ${key}`);
      delete obj[key];
      return true;
    }
  });
}

const state = reactive({ count: 0, user: { name: 'Tom' } });

state.count;          // [GET] count
state.count = 1;      // [SET] count = 1
state.user.name;      // [GET] user → [GET] name（懒递归）
state.age = 18;       // [SET] age = 18（新增属性也能拦截！）
delete state.age;     // [DELETE] age（删除属性也能拦截！）
```

### 3.5 Proxy 的优势

1. **可以拦截整个对象**，不需要遍历属性
2. **可以监听新增/删除属性**
3. **可以监听数组的索引和 `length` 变化**
4. **支持 `Map`、`Set`、`WeakMap`、`WeakSet`**
5. **懒递归**优化性能（访问时才递归代理深层对象）
6. **多达 13 种拦截方法**，功能强大

## 四、Proxy vs Object.defineProperty 对比

### 4.1 核心对比表

| 对比维度 | Object.defineProperty | Proxy |
|----------|----------------------|-------|
| **引入版本** | ES5 | ES6 |
| **劫持方式** | 劫持对象的**单个属性** | 劫持**整个对象** |
| **初始化方式** | 需遍历所有属性递归劫持 | 直接代理整个对象 |
| **新增属性** | ❌ 无法监听，需 `$set` | ✅ 自动监听 |
| **删除属性** | ❌ 无法监听，需 `$delete` | ✅ 自动监听 |
| **数组索引** | ❌ 无法监听（重写方法） | ✅ 自动监听 |
| **数组 length** | ❌ 无法监听 | ✅ 自动监听 |
| **Map/Set** | ❌ 不支持 | ✅ 支持 |
| **深层对象** | 初始化时递归遍历（性能差） | 懒递归（访问时代理，性能好） |
| **拦截操作数** | 仅 get/set | 13 种（get/set/has/deleteProperty/apply/construct 等） |
| **兼容性** | IE9+ | 不支持 IE，现代浏览器支持 |
| **性能** | 初始化慢，访问快 | 初始化快，访问稍慢（代理层开销） |

### 4.2 数组监听对比示例

```javascript
// ========== Object.defineProperty ==========
const arr1 = [1, 2, 3];
// 无法监听 arr1[0] = 100 的变化
// 无法监听 arr1.length = 0 的变化
// Vue2 的做法：重写数组原型方法
const arrayProto = Array.prototype;
const arrayMethods = Object.create(arrayProto);
['push', 'pop', 'shift', 'unshift', 'splice', 'sort', 'reverse'].forEach(method => {
  arrayMethods[method] = function(...args) {
    const result = arrayProto[method].apply(this, args);
    console.log(`数组方法被调用: ${method}`);
    return result;
  };
});

// ========== Proxy ==========
const arr2 = new Proxy([1, 2, 3], {
  set(target, key, value) {
    console.log(`设置 arr[${key}] = ${value}`);
    target[key] = value;
    return true;
  }
});

arr2[0] = 100;      // 设置 arr[0] = 100 ✅
arr2.push(4);       // 设置 arr[3] = 4 → 设置 arr[length] = 4 ✅
arr2.length = 0;    // 设置 arr[length] = 0 ✅
```

### 4.3 新增/删除属性对比

```javascript
// ========== Object.defineProperty ==========
const obj1 = {};
Object.defineProperty(obj1, 'name', {
  get() { return this._name; },
  set(v) { this._name = v; console.log('name changed'); }
});
obj1.age = 18;      // ❌ 无任何拦截，新增属性未被劫持

// ========== Proxy ==========
const obj2 = new Proxy({}, {
  set(target, key, value) {
    console.log(`设置 ${key} = ${value}`);
    target[key] = value;
    return true;
  },
  deleteProperty(target, key) {
    console.log(`删除 ${key}`);
    delete target[key];
    return true;
  }
});
obj2.age = 18;      // ✅ 设置 age = 18
delete obj2.age;    // ✅ 删除 age
```

## 五、Vue3 响应式原理基础

### 5.1 Vue3 为什么改用 Proxy？

Vue2 使用 `Object.defineProperty` 存在上述诸多限制，Vue3 全面改用 `Proxy` 实现响应式，带来了：

1. **性能提升**：懒递归 + 无需初始化遍历所有属性
2. **功能增强**：支持新增/删除属性、数组索引、Map/Set
3. **API 简化**：不再需要 `Vue.set` / `Vue.delete`
4. **包体积减小**：去掉了数组方法重写等补丁代码

### 5.2 Vue3 响应式核心简化实现

```javascript
// 依赖收集容器
const targetMap = new WeakMap();
let activeEffect = null;

// 追踪依赖
function track(target, key) {
  if (!activeEffect) return;
  let depsMap = targetMap.get(target);
  if (!depsMap) {
    depsMap = new Map();
    targetMap.set(target, depsMap);
  }
  let deps = depsMap.get(key);
  if (!deps) {
    deps = new Set();
    depsMap.set(key, deps);
  }
  deps.add(activeEffect);
}

// 触发更新
function trigger(target, key) {
  const depsMap = targetMap.get(target);
  if (!depsMap) return;
  const deps = depsMap.get(key);
  if (deps) {
    deps.forEach(effect => effect());
  }
}

// reactive 核心
function reactive(target) {
  return new Proxy(target, {
    get(obj, key) {
      track(obj, key);
      const result = obj[key];
      // 懒递归：深层对象在访问时才转为 reactive
      return typeof result === 'object' && result !== null 
        ? reactive(result) 
        : result;
    },
    set(obj, key, value) {
      obj[key] = value;
      trigger(obj, key);
      return true;
    },
    deleteProperty(obj, key) {
      delete obj[key];
      trigger(obj, key);
      return true;
    }
  });
}

// 副作用函数
function effect(fn) {
  activeEffect = fn;
  fn();
  activeEffect = null;
}

// ========== 使用示例 ==========
const state = reactive({ count: 0 });

effect(() => {
  console.log(`count = ${state.count}`); // 首次执行: count = 0
});

state.count++;  // 触发: count = 1
state.count++;  // 触发: count = 2
```

### 5.3 Vue3 响应式数据结构

```
targetMap (WeakMap)
  └── target (对象) → depsMap (Map)
                      └── key (属性名) → deps (Set)
                                          └── effect1, effect2, ...
```

- **WeakMap**：以目标对象为 key，对象被垃圾回收时依赖自动清除
- **Map**：以属性名为 key，存储该属性的依赖集合
- **Set**：存储所有依赖该属性的副作用函数，自动去重

### 5.4 ref 与 reactive 的区别

```javascript
// reactive：用于对象类型，返回 Proxy
const state = reactive({ count: 0 });
state.count++; // 直接访问属性

// ref：用于基本类型（也可用于对象），通过 .value 访问
const count = ref(0);
count.value++; // 必须通过 .value

// ref 的本质：内部用类的 getter/setter 实现（不是 Proxy）
class RefImpl {
  constructor(value) {
    this._value = value;
  }
  get value() {
    track(this, 'value');
    return this._value;
  }
  set value(newVal) {
    this._value = newVal;
    trigger(this, 'value');
  }
}
```

## 六、Proxy 的注意事项与进阶

### 6.1 Proxy 与 Reflect 配合使用

`Reflect` 也是 ES6 引入的 API，与 Proxy 一一对应，提供操作对象的标准方法：

```javascript
const proxy = new Proxy(obj, {
  get(target, key, receiver) {
    // receiver 指向代理对象本身，保证 this 正确
    return Reflect.get(target, key, receiver);
  },
  set(target, key, value, receiver) {
    // Reflect.set 返回布尔值，表示是否设置成功
    return Reflect.set(target, key, value, receiver);
  }
});
```

### 6.2 this 指向问题

```javascript
const user = {
  name: 'Tom',
  sayHi() {
    console.log(`Hi, I'm ${this.name}`);
  }
};

const proxy = new Proxy(user, {});
proxy.sayHi(); // Hi, I'm Tom — this 指向 proxy，正常工作

// 但如果目标对象有私有字段（#field），this 必须指向原对象
class Person {
  #age = 18;
  getAge() { return this.#age; }
}
const p = new Person();
const pProxy = new Proxy(p, {});
pProxy.getAge(); // ❌ TypeError: Cannot read private member #age
// 解决：在 get 中绑定 this
const pProxy2 = new Proxy(p, {
  get(target, key) {
    const val = Reflect.get(target, key);
    return typeof val === 'function' ? val.bind(target) : val;
  }
});
```

### 6.3 可撤销 Proxy

```javascript
const { proxy, revoke } = Proxy.revocable({ name: 'Tom' }, {
  get(target, key) {
    return target[key];
  }
});

console.log(proxy.name); // Tom
revoke(); // 撤销代理
console.log(proxy.name); // ❌ TypeError: Cannot perform 'get' on a proxy that has been revoked
```

### 6.4 性能考量

- Proxy 有一层代理开销，**频繁访问**时比直接访问慢约 10-20%
- 但 Vue3 通过**懒递归**和**缓存代理对象**（`proxyMap`）优化了整体性能
- 大型应用中，初始化性能提升远大于访问时的微小损耗

## 面试总结

Object.defineProperty用于直接在对象上定义一个新属性，或修改对象的现有属性，并返回该对象。Proxy是ES6引入的API，用于创建一个对象的代理，从而实现基本操作的拦截和自定义（如属性查找、赋值、枚举、函数调用等）。

两者的不同点有很多，例如： 
1. Object.defineProperty只会在对象属性基础上进行新建和修改操作，Proxy可以拦截这个对象，可以监听新增/删除的属性。
2. Object.defineProperty不支持Map、Set、WeakMap、WeakSet等数据结构，Proxy支持。
3. Object.defineProperty无法监听数组索引和length变化，Proxy支持。

>就是你Object.defineProperty监听不了的对象属性操作，我Proxy要监听，你不支持的数据类型，我Proxy支持，你监听不了的数组,我Proxy可以监听。先斩后奏，皇权特许!
