## 一、Class（类）

ES6 引入了 `class` 关键字，它本质上是基于原型继承的**语法糖**，让面向对象的写法更清晰、更接近传统语言。

### 1. 基本定义

```js
class Person {
  // 构造函数，new 时自动调用
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // 实例方法（定义在原型上）
  sayHello() {
    console.log(`你好，我是 ${this.name}，今年 ${this.age} 岁`);
  }
}

const p = new Person('张三', 25);
p.sayHello(); // 你好，我是 张三，今年 25 岁
```

> 注意：类内部定义的方法**不可枚举**，且类内部默认处于**严格模式**。

### 2. 静态方法与静态属性

用 `static` 修饰，属于类本身，不能通过实例调用：

```js
class Utils {
  static version = '1.0.0';

  static add(a, b) {
    return a + b;
  }
}

console.log(Utils.version); // 1.0.0
console.log(Utils.add(1, 2)); // 3
```

### 3. getter / setter

```js
class User {
  constructor(name) {
    this._name = name;
  }

  get name() {
    return this._name.toUpperCase();
  }

  set name(value) {
    this._name = value.trim();
  }
}

const u = new User('alice');
console.log(u.name); // ALICE
u.name = '  Bob  ';
console.log(u.name); // BOB
```

### 4. 继承（extends + super）

```js
class Student extends Person {
  constructor(name, age, grade) {
    super(name, age); // 调用父类构造函数，必须在使用 this 之前
    this.grade = grade;
  }

  // 重写父类方法
  sayHello() {
    super.sayHello(); // 调用父类方法
    console.log(`我在读 ${this.grade} 年级`);
  }
}

const s = new Student('李四', 18, '高三');
s.sayHello();
```

### 5. 私有字段（ES2022）

以 `#` 开头的字段是真正的私有，外部无法访问：

```js
class Account {
  #balance = 0; // 私有字段

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}

const acc = new Account();
acc.deposit(100);
console.log(acc.getBalance()); // 100
// console.log(acc.#balance); // 语法错误，外部不可访问
```

### 小结

| 特性 | 说明 |
|------|------|
| `constructor` | 构造方法，`new` 时执行 |
| `static` | 静态成员，挂在类上 |
| `extends` | 继承 |
| `super` | 调用父类构造或方法 |
| `#xxx` | 私有字段 |

## 二、Module（import / export）

ES6 首次在语言层面引入了模块系统，取代了过去的 CommonJS、AMD 等方案。模块有独立作用域，默认严格模式。

### 1. 命名导出（Named Export）

一个模块可以有多个命名导出：

```js
// math.js
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export function multiply(a, b) {
  return a * b;
}
```

导入时必须用**花括号**，且名字要对应：

```js
// main.js
import { PI, add, multiply } from './math.js';

console.log(PI);        // 3.14159
console.log(add(1, 2)); // 3
```

### 2. 默认导出（Default Export）

每个模块**只能有一个**默认导出：

```js
// logger.js
export default function log(msg) {
  console.log('[LOG]', msg);
}
```

导入时**不用花括号**，且可以自定义名字：

```js
import myLog from './logger.js';
myLog('hello'); // [LOG] hello
```

### 3. 混合导入

```js
import React, { useState, useEffect } from 'react';
```

### 4. 重命名（as）

```js
// 导出时重命名
export { add as sum };

// 导入时重命名
import { add as sum } from './math.js';
```

### 5. 整体导入

```js
import * as math from './math.js';
console.log(math.add(1, 2));
```

### 6. 重新导出

```js
export { add, multiply } from './math.js';
```

### 7. 动态导入（ES2020）

`import()` 返回 Promise，可按需加载：

```js
button.addEventListener('click', async () => {
  const math = await import('./math.js');
  console.log(math.add(1, 2));
});
```

### 模块的关键特点

- **静态结构**：`import/export` 只能在顶层，不能放在条件或函数内（动态 `import()` 除外）
- **独立作用域**：模块内的变量不会污染全局
- **默认严格模式**
- **单例**：同一个模块多次导入，只执行一次

## 三、可选链（Optional Chaining）`?.`

ES2020 引入，用于安全地访问深层嵌套的属性，避免 `Cannot read property of undefined` 报错。

### 1. 基本用法

```js
const user = {
  name: '张三',
  address: {
    city: '北京'
  }
};

// 传统写法
const city1 = user && user.address && user.address.city;

// 可选链写法
const city2 = user?.address?.city; // '北京'
```

如果中间某一层是 `null` 或 `undefined`，表达式**短路返回 `undefined`**，而不是报错：

```js
console.log(user?.phone?.number); // undefined，不报错
```

### 2. 数组访问

```js
const arr = [1, 2, 3];
console.log(arr?.[5]); // undefined
```

### 3. 函数调用

```js
const obj = {
  foo: () => 'hello'
};

console.log(obj.foo?.());   // 'hello'
console.log(obj.bar?.());   // undefined（bar 不存在，不报错）
```

### 4. 短路特性

一旦遇到 `null/undefined`，后面的表达式不再执行：

```js
let count = 0;
const result = undefined?.[count++];
console.log(count); // 0，count++ 没有执行
```

### 与 `&&` 的区别

| 写法 | 行为 |
|------|------|
| `a && a.b` | 遇到任何 falsy（`0`、`''`、`false`）都会短路 |
| `a?.b` | 只在 `null/undefined` 时短路 |

可选链更精准，只处理"不存在"的情况。

## 四、空值合并（Nullish Coalescing）`??`

ES2020 引入，是一个逻辑运算符，**只有左侧为 `null` 或 `undefined` 时才返回右侧的值**。

### 1. 基本用法

```js
const name = null ?? '默认名';
console.log(name); // '默认名'

const age = 0 ?? 18;
console.log(age); // 0（0 不是 null/undefined，所以保留 0）
```

### 2. 与 `||` 的关键区别

这是最容易混淆的点：

```js
console.log(0 || 100);   // 100（0 是 falsy）
console.log(0 ?? 100);   // 0   （0 不是 null/undefined）

console.log('' || '默认');  // '默认'
console.log('' ?? '默认');  // ''

console.log(false || true); // true
console.log(false ?? true); // false
```

| 运算符 | 触发右侧的条件 |
|--------|----------------|
| `\|\|` | 左侧为任意 falsy（`0`、`''`、`false`、`null`、`undefined`、`NaN`） |
| `??` | 左侧仅为 `null` 或 `undefined` |

所以当 `0`、空字符串、`false` 是**合法值**时，必须用 `??` 而不是 `||`。

### 3. 与可选链配合（最常见用法）

```js
const user = {};

const city = user?.address?.city ?? '未知城市';
console.log(city); // '未知城市'
```

这是处理配置项、接口返回数据的标准模式：先安全访问，再给默认值。

### 4. 注意事项

`??` 不能直接与 `&&` 或 `||` 混用，必须加括号：

```js
// 语法错误
// const x = a || b ?? c;

// 正确
const x = (a || b) ?? c;
```
