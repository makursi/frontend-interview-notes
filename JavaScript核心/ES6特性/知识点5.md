# JavaScript ES6+：Iterator、for...of 与 for...in 详解

## 一、Iterator（迭代器）

### 1. 什么是 Iterator

Iterator 是 ES6 引入的一种**统一接口机制**，为各种不同的数据结构提供统一的访问方式。它是一个对象，提供 `next()` 方法，每次调用返回一个包含 `value` 和 `done` 属性的对象。

```javascript
// 手动实现一个简单的迭代器
function createIterator(array) {
  let index = 0;
  return {
    next() {
      return index < array.length
        ? { value: array[index++], done: false }
        : { value: undefined, done: true };
    }
  };
}

const it = createIterator([1, 2, 3]);
console.log(it.next()); // { value: 1, done: false }
console.log(it.next()); // { value: 2, done: false }
console.log(it.next()); // { value: 3, done: false }
console.log(it.next()); // { value: undefined, done: true }
```

### 2. 可迭代协议（Iterable Protocol）

一个对象只要部署了 `Symbol.iterator` 属性（该属性是一个返回迭代器的函数），它就是**可迭代的**。

```javascript
const obj = {
  data: ['a', 'b', 'c'],
  [Symbol.iterator]() {
    let index = 0;
    return {
      next: () => {
        return index < this.data.length
          ? { value: this.data[index++], done: false }
          : { value: undefined, done: true };
      }
    };
  }
};

for (const item of obj) {
  console.log(item); // a, b, c
}
```
>注意箭头函数的this指向,当 [Symbol.iterator] 以正确的方式被调用（作为 obj 的方法）时，箭头函数才会被创建，并在那一刻把 this 固定为 obj。


### 3. 原生可迭代的数据结构

以下数据结构原生部署了 `Symbol.iterator`：
- `Array`
- `String`
- `Map`
- `Set`
- `TypedArray`
- 函数的 `arguments` 对象
- `NodeList` 等 DOM 集合

```javascript
// 字符串可迭代
for (const char of 'hello') {
  console.log(char); // h e l l o
}

// Map 迭代返回 [key, value]
const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) {
  console.log(key, value);
}
```

### 4. Iterator 的应用场景

- `for...of` 循环
- 扩展运算符 `...`
- 解构赋值
- `Array.from()`
- `Promise.all()`、`Promise.race()`
- `yield*`

## 二、for...of 循环

### 1. 基本概念

`for...of` 是 ES6 引入的**遍历可迭代对象**的语法，它内部调用的就是 `Symbol.iterator` 接口。

```javascript
const arr = [10, 20, 30];
for (const value of arr) {
  console.log(value); // 10, 20, 30
}
```

### 2. 特点

- **遍历的是值（value）**，不是键或索引
- 只能遍历**可迭代对象**（部署了 `Symbol.iterator`）
- 普通对象默认**不能**用 `for...of` 遍历
- 可以用 `break`、`continue`、`return` 中断
- 不遍历原型链上的属性

### 3. 遍历数组时获取索引

```javascript
const arr = ['a', 'b', 'c'];

// 方式一：entries()
for (const [index, value] of arr.entries()) {
  console.log(index, value); // 0 a, 1 b, 2 c
}

// 方式二：keys()
for (const index of arr.keys()) {
  console.log(index); // 0, 1, 2
}
```

### 4. 遍历普通对象的方法

普通对象没有 `Symbol.iterator`，需要手动处理：

```javascript
const obj = { a: 1, b: 2, c: 3 };

// Object.keys / values / entries 返回数组，可迭代
for (const key of Object.keys(obj)) {
  console.log(key); // a, b, c
}

for (const value of Object.values(obj)) {
  console.log(value); // 1, 2, 3
}

for (const [key, value] of Object.entries(obj)) {
  console.log(key, value);
}
```

## 三、for...in 循环

### 1. 基本概念

`for...in` 是 ES5 就存在的语法，用于**遍历对象的可枚举属性**（包括原型链上的）。

```javascript
const obj = { a: 1, b: 2, c: 3 };
for (const key in obj) {
  console.log(key); // a, b, c
  console.log(obj[key]); // 1, 2, 3
}
```

### 2. 特点

- **遍历的是键（key / 属性名）**，不是值
- 遍历对象的**可枚举属性**，包括**原型链**上继承的属性
- 可以遍历普通对象
- 遍历顺序不保证（尤其是数字键会按升序优先遍历）
- 通常需要配合 `hasOwnProperty` 过滤原型属性

### 3. 原型链问题

```javascript
function Person(name) {
  this.name = name;
}
Person.prototype.age = 18;

const p = new Person('Tom');

for (const key in p) {
  console.log(key); // name, age  ← age 是原型上的属性也被遍历了
}

// 过滤原型属性
for (const key in p) {
  if (p.hasOwnProperty(key)) {
    console.log(key); // name  ← 只输出自身属性
  }
}
```

### 4. 遍历数组的坑

```javascript
const arr = ['a', 'b', 'c'];
arr.extra = 'extra'; // 给数组添加自定义属性

for (const key in arr) {
  console.log(key); // '0', '1', '2', 'extra'  ← 自定义属性也被遍历
  console.log(typeof key); // string  ← 索引是字符串，不是数字
}
```

## 四、for...of 与 for...in 的核心区别

| 对比维度 | for...of | for...in |
|---------|----------|----------|
| **遍历目标** | 可迭代对象（Array、Map、Set、String等） | 任意对象的可枚举属性 |
| **遍历内容** | 值（value） | 键名（key / 属性名） |
| **普通对象** | 不能直接遍历（无 Symbol.iterator） | 可以遍历 |
| **原型链属性** | 不遍历 | 会遍历（需 hasOwnProperty 过滤） |
| **数组自定义属性** | 不遍历 | 会遍历 |
| **数组索引类型** | 通过 entries() 得到数字索引 | 索引是字符串类型 |
| **遍历顺序** | 按迭代器顺序（有序） | 不保证顺序（数字键优先） |
| **引入版本** | ES6 | ES5 |
| **中断** | 支持 break/continue | 支持 break/continue |

### 代码对比示例

```javascript
const arr = ['x', 'y', 'z'];
arr.tag = 'myArray';

// for...in —— 遍历键名（字符串），包含自定义属性
for (const key in arr) {
  console.log('for-in:', key, typeof key);
}
// 输出: 0 string, 1 string, 2 string, tag string

// for...of —— 遍历值，不包含自定义属性
for (const value of arr) {
  console.log('for-of:', value);
}
// 输出: x, y, z
```

## 五、Iterator 与 for...of 的关系

`for...of` 本质上是 Iterator 的**语法糖**，它的内部执行逻辑：

```javascript
// for...of 的伪代码实现
const iterator = iterable[Symbol.iterator]();
let result = iterator.next();

while (!result.done) {
  const value = result.value;
  // 执行循环体
  result = iterator.next();
}
```

所以：
- **Iterator 是底层机制**，定义了"如何遍历"
- **for...of 是上层语法**，提供了简洁的遍历写法
- 只要一个对象实现了 `Symbol.iterator`，就能被 `for...of` 消费

---

## 六、使用建议

1. **遍历数组**：优先用 `for...of`（简洁、直接拿值、不会遍历自定义属性）
2. **遍历普通对象的属性**：用 `for...in`（记得加 `hasOwnProperty`）或 `Object.keys/values/entries` + `for...of`
3. **遍历 Map/Set**：必须用 `for...of`
4. **需要索引和值**：用 `for...of` + `entries()`
5. **不要用 `for...in` 遍历数组**（顺序不保证、会遍历自定义属性、索引是字符串）

## 七、Generator 与 Iterator 的关系（补充）

Generator 函数是生成 Iterator 的便捷方式，调用 Generator 函数返回一个迭代器对象：

```javascript
function* gen() {
  yield 1;
  yield 2;
  yield 3;
}

const g = gen();
console.log(g.next()); // { value: 1, done: false }
console.log(g.next()); // { value: 2, done: false }

// Generator 返回的对象天然可迭代
for (const val of gen()) {
  console.log(val); // 1, 2, 3
}
```

这也是为什么 Generator 可以直接用 `for...of` 遍历的原因——它的返回值自动部署了 `Symbol.iterator`。

---

## 面试总结

Iterator 是统一遍历的底层接口，`for...of` 是消费 Iterator 的语法（遍历值），`for...in` 是遍历对象可枚举属性名的旧语法（会爬原型链）。日常开发中，数组和可迭代集合用 `for...of`，普通对象属性用 `for...in` 或 `Object.keys`。
