# 箭头函数、解构赋值、模板字符串、扩展运算符

## 一、箭头函数（Arrow Functions）

### 1. 基本语法

箭头函数用 `=>` 定义，是普通函数的简写形式：

```
// 普通函数
const add = function(a, b) {
  return a + b;
};

// 箭头函数
const add = (a, b) => {
  return a + b;
};

// 更简洁：单表达式可省略 {} 和 return
const add = (a, b) => a + b;
```

### 2. 语法简写规则

| 场景 | 写法 |
| --- | --- |
| 无参数 | `() => { ... }` |
| 单个参数 | `x => { ... }`（括号可省） |
| 多个参数 | `(a, b) => { ... }` |
| 单表达式返回 | `x => x * 2` |
| 返回对象字面量 | `x => ({ name: x })`（必须加括号） |

```
const nums = [1, 2, 3];
const doubled = nums.map(x => x * 2); // [2, 4, 6]

// 返回对象时注意括号
const makeUser = name => ({ name: name, age: 0 });
```

### 3. 核心特性：不绑定自己的 `this`

这是箭头函数**最重要**的特点。箭头函数没有自己的 `this`，它会捕获**定义时所在作用域**的 `this`（词法 this）。

```
const obj = {
  name: 'Alice',
  sayHi: function() {
    // 普通函数内的 this 指向 obj
    setTimeout(() => {
      // 箭头函数捕获外层 sayHi 的 this → obj
      console.log('Hi, ' + this.name); // Hi, Alice
    }, 100);
  }
};
obj.sayHi();
```

对比普通函数的痛点：

```
const obj = {
  name: 'Alice',
  sayHi: function() {
    setTimeout(function() {
      console.log(this.name); // undefined（this 指向全局或 undefined）
    }, 100);
  }
};
```

### 4. 不能使用箭头函数的场景

- **作为对象方法**：会丢失 `this`，无法访问对象属性```
const obj = {
  name: 'Alice',
  sayHi: () => console.log(this.name) // this 不是 obj
};
```
- **作为构造函数**：箭头函数没有 `prototype`，不能 `new`
- **需要 `arguments` 对象时**：箭头函数不绑定 `arguments`
- **需要动态 `this` 时**（如事件回调、jQuery 回调）

## 二、解构赋值（Destructuring Assignment）

解构赋值可以从数组或对象中**快速提取值**并赋给变量。

### 1. 数组解构

```
const arr = [1, 2, 3];

// 基本解构
const [a, b, c] = arr;
console.log(a, b, c); // 1 2 3

// 跳过元素
const [first, , third] = arr;
console.log(first, third); // 1 3

// 剩余元素（rest）
const [x, ...rest] = arr;
console.log(rest); // [2, 3]

// 默认值
const [p, q, r, s = 4] = arr;
console.log(s); // 4
```

### 2. 对象解构

```
const user = { name: 'Bob', age: 25, city: 'Beijing' };

// 基本解构（变量名必须与属性名一致）
const { name, age } = user;
console.log(name, age); // Bob 25

// 重命名变量
const { name: userName, age: userAge } = user;
console.log(userName); // Bob

// 默认值
const { name, age, gender = 'male' } = user;
console.log(gender); // male

// 重命名 + 默认值
const { name: n = 'Anonymous', age: a = 0 } = user;
```

### 3. 嵌套解构

```
const data = {
  user: {
    name: 'Carol',
    address: { city: 'Shanghai', zip: '200000' }
  }
};

const {
  user: {
    name,
    address: { city }
  }
} = data;
console.log(name, city); // Carol Shanghai
```

### 4. 常见应用场景

**① 交换变量（无需临时变量）**

```
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2 1
```

**② 函数参数解构**

```
function greet({ name, age = 18 }) {
  console.log(`Hello ${name}, you are ${age}`);
}
greet({ name: 'Dave' }); // Hello Dave, you are 18
```

**③ 函数返回多个值**

```
function getPoint() {
  return { x: 10, y: 20 };
}
const { x, y } = getPoint();
```

**④ 导入模块时按需提取**

```
import { useState, useEffect } from 'react';
```

## 三、模板字符串（Template Literals）

### 1. 基本用法

用**反引号 `\``** 包裹，支持多行字符串和变量插值：

```
const name = 'Eve';
const age = 30;

// 传统拼接
const str1 = 'My name is ' + name + ', I am ' + age + ' years old.';

// 模板字符串
const str2 = `My name is ${name}, I am ${age} years old.`;
```

### 2. 多行字符串

```
// 传统方式需要 \n
const html1 = '<div>\n  <p>Hello</p>\n</div>';

// 模板字符串直接换行
const html2 = `
<div>
  <p>Hello</p>
</div>
`;
```

### 3. 表达式插值 `${}`

`${}` 中可以放**任意 JavaScript 表达式**：

```
const a = 5, b = 10;
console.log(`Sum: ${a + b}`);        // Sum: 15
console.log(`Double: ${a * 2}`);     // Double: 10

// 调用函数
function toUpper(s) { return s.toUpperCase(); }
console.log(`Hello ${toUpper('world')}`); // Hello WORLD

// 三元运算
const score = 85;
console.log(`Result: ${score >= 60 ? 'Pass' : 'Fail'}`); // Result: Pass
```

### 4. 标签模板（Tagged Templates）

可以用函数自定义模板字符串的处理逻辑：

```
function highlight(strings, ...values) {
  // strings: 静态文本数组
  // values: 插值表达式的结果
  return strings.reduce((result, str, i) => {
    return result + str + (values[i] ? `【${values[i]}】` : '');
  }, '');
}

const name = 'Frank';
const result = highlight`My name is ${name} and I am ${28} years old.`;
console.log(result); // My name is 【Frank】 and I am 【28】 years old.
```

常见应用：`styled-components`、SQL 语句防注入、i18n 国际化等。

## 四、扩展运算符（Spread Operator）

扩展运算符用三个点 `...` 表示，作用是**将可迭代对象展开为单独的元素**。

### 1. 数组展开

```
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

// 数组合并（替代 concat）
const merged = [...arr1, ...arr2];
console.log(merged); // [1, 2, 3, 4, 5, 6]

// 数组拷贝（浅拷贝）
const copy = [...arr1];
console.log(copy); // [1, 2, 3]

// 中间插入
const result = [0, ...arr1, 4];
console.log(result); // [0, 1, 2, 3, 4]
```

### 2. 对象展开（ES2018）

```
const defaults = { theme: 'light', lang: 'en' };
const userConfig = { theme: 'dark' };

// 对象合并（后面的覆盖前面的）
const config = { ...defaults, ...userConfig };
console.log(config); // { theme: 'dark', lang: 'en' }

// 对象拷贝 + 新增/修改属性
const user = { name: 'Grace', age: 25 };
const updated = { ...user, age: 26, city: 'Beijing' };
console.log(updated); // { name: 'Grace', age: 26, city: 'Beijing' }
```

### 3. 函数调用中展开参数

```
const nums = [1, 2, 3];

// 替代 apply
console.log(Math.max(...nums)); // 3
// 等价于 Math.max(1, 2, 3)

function sum(a, b, c) {
  return a + b + c;
}
console.log(sum(...nums)); // 6
```

### 4. 字符串展开

```
const str = 'hello';
const chars = [...str];
console.log(chars); // ['h', 'e', 'l', 'l', 'o']

// 正确处理 Unicode 字符
const emoji = '😀🎉';
console.log([...emoji]); // ['😀', '🎉']
```

### 5. 与剩余参数（Rest）的区别

`...` 在不同位置含义不同：

```
// 扩展运算符：在"赋值/调用"右侧，把数组拆开
const arr = [1, 2, 3];
console.log(...arr); // 1 2 3

// 剩余参数：在"函数参数"或"解构左侧"，把多个值收集为数组
function fn(first, ...rest) {
  console.log(rest); // [2, 3]
}
fn(1, 2, 3);

const [a, ...rest] = [1, 2, 3];
console.log(rest); // [2, 3]
```

### 6. 注意事项

- **浅拷贝**：扩展运算符只做一层拷贝，嵌套对象仍是引用```
const obj = { a: { b: 1 } };
const copy = { ...obj };
copy.a.b = 2;
console.log(obj.a.b); // 2（被影响了）
```
- 对象的扩展运算符是 **ES2018** 引入的，数组的是 ES6
- 只能展开**可迭代对象**（数组、字符串、Set、Map 等），普通对象不能用 `...` 展开到数组中
