# CSS 布局知识点详解

## 一、Flex 布局（弹性盒子）

Flexbox 是一种**一维**布局模型，一次只处理一个维度（行或列）上的元素布局。它给子元素之间提供了强大的空间分布和对齐能力。

### 1. 主轴与交叉轴

使用 Flex 布局时，所有属性都围绕**两根轴线**展开：

| 轴 | 定义 | 方向 |
| --- | --- | --- |
| **主轴（main axis）** | 由 `flex-direction` 定义 | `row` → 水平方向；`column` → 垂直方向 |
| **交叉轴（cross axis）** | 垂直于主轴 | 主轴水平时交叉轴垂直；主轴垂直时交叉轴水平 |

`flex-direction` 有四个取值：

- `row`（默认）：主轴水平，从左到右
- `row-reverse`：主轴水平，从右到左
- `column`：主轴垂直，从上到下
- `column-reverse`：主轴垂直，从下到上

> 
> **关键理解**：`justify-content` 永远控制**主轴**对齐，`align-items` 永远控制**交叉轴**对齐。当 `flex-direction` 改变时，它们控制的物理方向也会跟着变。

### 2. Flex 容器属性

#### （1）`justify-content` — 主轴对齐

控制所有 flex 项目在**主轴**上的对齐方式，初始值为 `flex-start`。

| 值 | 效果 |
| --- | --- |
| `flex-start` | 从主轴起始线排列（默认） |
| `flex-end` | 从主轴终止线排列 |
| `center` | 居中排列 |
| `space-between` | 两端对齐，元素之间间隔相等 |
| `space-around` | 每个元素两侧空间相等（首尾间距是中间间距的一半） |
| `space-evenly` | 所有间距完全相等 |

#### （2）`align-items` — 交叉轴对齐

控制所有 flex 项目在**交叉轴**上的对齐方式，初始值为 `stretch`。

| 值 | 效果 |
| --- | --- |
| `stretch` | 拉伸填满交叉轴（默认，所以 flex 项默认等高） |
| `flex-start` | 交叉轴起始线对齐 |
| `flex-end` | 交叉轴终止线对齐 |
| `center` | 交叉轴居中 |
| `baseline` | 按文字基线对齐 |

#### （3）其他容器属性

- `flex-wrap: nowrap | wrap | wrap-reverse` — 控制是否换行。默认 `nowrap`，元素会缩小以适应一行；设为 `wrap` 时超出则换行。
- `flex-flow: <direction> <wrap>` — `flex-direction` 和 `flex-wrap` 的简写，如 `flex-flow: row wrap`。
- `align-content` — 多行时交叉轴方向的行与行之间的对齐（仅在 `wrap` 换行后生效）。

### 3. Flex 项目属性

#### （1）`flex-grow` — 增长比例

定义项目在**有剩余空间**时的放大比例，默认 `0`（不放大）。值为正整数时按比例分配剩余空间。

```
容器 500px，3 个元素各 100px，剩余 200px
若都设 flex-grow: 1 → 各分得 200/3 ≈ 66.7px，最终各 166.7px
若第一个 flex-grow: 2，其余为 1 → 第一个分 100px，其余各分 50px
```

#### （2）`flex-shrink` — 收缩比例

定义项目在**空间不足**时的缩小比例，默认 `1`（允许缩小）。值越大收缩越多，设为 `0` 则不缩小。

#### （3）`flex-basis` — 基准尺寸

定义项目在分配空间之前的**初始大小**，默认 `auto`（即取元素的 width/height 或内容尺寸）。

#### （4）`flex` 缩写（重点）

`flex` 是 `flex-grow flex-shrink flex-basis` 的简写，**按此顺序书写**。日常开发中几乎都用简写。

| 简写 | 等同于 | 含义 |
| --- | --- | --- |
| `flex: initial` | `flex: 0 1 auto` | 不放大，可缩小，基准为 auto（默认值） |
| `flex: auto` | `flex: 1 1 auto` | 可放大可缩小，基准为 auto |
| `flex: none` | `flex: 0 0 auto` | 不可伸缩，固定尺寸 |
| `flex: 1` | `flex: 1 1 0` | 等比例分配（最常用！） |
| `flex: 2` | `flex: 2 1 0` | 占比是 `flex:1` 元素的两倍 |

> 
> **面试高频**：`flex: 1` 本质是 `flex: 1 1 0%`，意味着 `flex-basis: 0`，所有项目从同一起点按 `flex-grow` 比例分配空间，实现真正的等分布局。

#### （5）其他项目属性

- `align-self` — 覆盖容器的 `align-items`，单独控制某个项目的交叉轴对齐。
- `order` — 控制项目排列顺序，默认 `0`，值越小越靠前。

## 二、Grid 布局（网格布局）

CSS Grid 是一种**二维**布局系统，可以同时控制行和列，适合布局页面主要区域或复杂 UI。

### 1. 核心概念

| 概念 | 说明 |
| --- | --- |
| **网格容器（Grid Container）** | 设置 `display: grid` 的元素，其直接子元素成为网格项 |
| **网格轨道（Grid Track）** | 两条相邻网格线之间的空间，即行或列 |
| **网格线（Grid Line）** | 划分网格的线，从 1 开始编号，也支持负数（从末尾数） |
| **网格单元格（Grid Cell）** | 相邻行列线交叉形成的最小单位 |
| **网格区域（Grid Area）** | 由任意多条网格线围成的矩形区域，可跨多个单元格 |

### 2. 容器属性

#### （1）`grid-template-columns` / `grid-template-rows` — 定义行列

```
/* 固定尺寸 */
grid-template-columns: 200px 200px 200px;

/* fr 单位（可用空间的比例） */
grid-template-columns: 1fr 2fr 1fr;  /* 按 1:2:1 分配 */

/* 混合固定与弹性 */
grid-template-columns: 200px 1fr 1fr;  /* 第一列固定 200px，剩余平分 */

/* repeat() 函数 */
grid-template-columns: repeat(3, 1fr);  /* 等同于 1fr 1fr 1fr */
grid-template-columns: 20px repeat(6, 1fr) 20px;

/* minmax() 函数 */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
/* 自动填充：每列至少 200px，最多平分，实现响应式卡片布局 */
```

- `fr` 单位：代表网格容器中**可用空间**的一份，会先扣除固定尺寸和 gap 再分配。
- `auto-fill` vs `auto-fit`：`auto-fill` 保留空轨道，`auto-fit` 会折叠空轨道让现有项扩展。

#### （2）`gap` — 网格间距

```
gap: 10px;                              /* 行列间距都是 10px */
row-gap: 1em;                           /* 仅行间距 */
column-gap: 10px;                       /* 仅列间距 */
gap: 10px 20px;                         /* 行间距 10px，列间距 20px */
```

> 
> 旧版属性带 `grid-` 前缀（`grid-gap` 等），现在推荐使用无前缀版本，前缀版作为别名保留。

#### （3）对齐属性

| 属性 | 控制方向 | 作用对象 |
| --- | --- | --- |
| `justify-items` | 行内（水平） | 网格项在单元格内的水平对齐 |
| `align-items` | 块级（垂直） | 网格项在单元格内的垂直对齐 |
| `place-items` | — | 以上两者的简写（align / justify） |
| `justify-content` | 行内 | 整个网格在容器内的水平对齐（轨道总宽 < 容器时） |
| `align-content` | 块级 | 整个网格在容器内的垂直对齐 |

```
place-items: center center;  /* 所有网格项在各自单元格内水平垂直居中 */
```

#### （4）`grid-template-areas` — 命名区域布局

```
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "left   main   right"
    "footer footer footer";
}
.header { grid-area: header; }
.left   { grid-area: left; }
.main   { grid-area: main; }
.right  { grid-area: right; }
.footer { grid-area: footer; }
```

直观地用"画地图"的方式定义布局，可读性极强。

#### （5）`grid-auto-flow` — 自动排列方向

默认 `row`，项目按行优先填充；设为 `column` 则按列优先填充。`dense` 值可让小项目回填空隙。

### 3. 项目属性

```
/* 基于网格线定位 */
grid-column: 1 / 3;        /* 从第 1 条列线到第 3 条列线，跨 2 列 */
grid-column: 1 / span 2;   /* 从第 1 条线开始，跨 2 列（等价写法） */
grid-row: 2 / 4;           /* 从第 2 条行线到第 4 条行线 */

/* 基于命名区域 */
grid-area: main;

/* 单独控制某个项的对齐 */
justify-self: center;      /* 水平 */
align-self: center;        /* 垂直 */
place-self: center;        /* 简写 */
```

## 三、三栏布局实现

三栏布局：**左右两栏固定宽度，中间栏自适应**，且中间栏在 HTML 中优先渲染（写在最前面）。

### 1. 圣杯布局（Holy Grail）

核心思路：父容器用 `padding` 为左右栏预留空间，三栏全部浮动，左右栏用**负 margin** 拉到与中间栏同行，再用**相对定位**偏移到预留位置。

```
<div class="container">
  <div class="main">中间栏</div>
  <div class="left">左栏</div>
  <div class="right">右栏</div>
</div>
```

```
.container {
  padding: 0 200px;          /* 为左右栏各预留 200px */
}
.main, .left, .right {
  float: left;
}
.main {
  width: 100%;               /* 占满容器内容区 */
}
.left {
  width: 200px;
  margin-left: -100%;        /* 拉到上一行最左端 */
  position: relative;
  left: -200px;              /* 左移到 padding 区域 */
}
.right {
  width: 200px;
  margin-left: -200px;       /* 拉到上一行最右端 */
  position: relative;
  right: -200px;             /* 右移到 padding 区域 */
}
```

**缺点**：当中间栏宽度小于左右栏时，布局会错乱；需要相对定位，较复杂。

### 2. 双飞翼布局

淘宝 UED 对圣杯布局的改进。核心思路：中间栏内部再嵌套一个子元素，用子元素的 `margin` 为左右栏预留空间，**不需要相对定位**。

```
<div class="container">
  <div class="main">
    <div class="content">中间栏内容</div>  <!-- 额外嵌套 -->
  </div>
  <div class="left">左栏</div>
  <div class="right">右栏</div>
</div>
```

```
.main, .left, .right {
  float: left;
}
.main {
  width: 100%;
}
.content {
  margin: 0 200px;           /* 用内部元素的 margin 预留空间 */
}
.left {
  width: 200px;
  margin-left: -100%;        /* 拉到最左 */
}
.right {
  width: 200px;
  margin-left: -200px;       /* 拉到最右 */
}
```

**与圣杯的区别**：

- 圣杯：父容器 `padding` + 左右栏 `relative` 定位
- 双飞翼：中间栏嵌套子元素 + 子元素 `margin`，无需定位
- 双飞翼更稳定，但多了一层 DOM 结构

### 3. Flex 实现（推荐，最简单）

```
<div class="container">
  <div class="main">中间栏</div>
  <div class="left">左栏</div>
  <div class="right">右栏</div>
</div>
```

```
.container {
  display: flex;
}
.main {
  flex: 1;                   /* 自适应，占满剩余空间 */
  order: 2;                  /* 视觉上排中间 */
}
.left {
  width: 200px;
  flex-shrink: 0;            /* 不缩小 */
  order: 1;
}
.right {
  width: 200px;
  flex-shrink: 0;
  order: 3;
}
```

用 `order` 调整视觉顺序，HTML 中中间栏仍写在最前面优先加载。代码简洁，现代项目首选。

### 4. Grid 实现（最优雅）

```
.container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-areas: "left main right";
}
.left  { grid-area: left; }
.main  { grid-area: main; }
.right { grid-area: right; }
```

一行 `grid-template-columns` 搞定，无需浮动、负 margin、定位。可读性最强。

### 5. 绝对定位实现

```
.container {
  position: relative;
}
.left {
  position: absolute;
  left: 0;
  top: 0;
  width: 200px;
}
.right {
  position: absolute;
  right: 0;
  top: 0;
  width: 200px;
}
.main {
  margin: 0 200px;           /* 左右留出空间 */
}
```

**缺点**：左右栏脱离文档流，容器高度由中间栏决定，若左右栏更高会溢出；不灵活。

## 四、垂直水平居中的 N 种方法

### 方法 1：Flex（最推荐）

```
.parent {
  display: flex;
  justify-content: center;   /* 主轴居中 */
  align-items: center;       /* 交叉轴居中 */
}
```

子元素无需任何设置，**一行父元素样式搞定**，现代项目首选。

### 方法 2：Grid（更简洁）

```
.parent {
  display: grid;
  place-items: center;       /* align-items + justify-items 简写 */
}
```

只需一行 `place-items: center`，是目前最简短的写法。

### 方法 3：绝对定位 + transform（未知宽高）

```
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
.parent { position: relative; }
```

不需要知道子元素尺寸，`transform` 的百分比基于自身宽高计算。

### 方法 4：绝对定位 + margin: auto（已知有宽高）

```
.child {
  position: absolute;
  top: 0; right: 0; bottom: 0; left: 0;
  margin: auto;
  width: 200px;
  height: 100px;
}
```

四个方向都设为 0，再 `margin: auto`，浏览器会自动分配剩余空间实现居中。需要元素有确定尺寸。

### 方法 5：绝对定位 + 负 margin（已知宽高）

```
.child {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 200px;
  height: 100px;
  margin-top: -50px;         /* 高度的一半 */
  margin-left: -100px;       /* 宽度的一半 */
}
```

经典老方法，必须知道子元素精确尺寸。

### 方法 6：table-cell（兼容老浏览器）

```
.parent {
  display: table-cell;
  vertical-align: middle;    /* 垂直居中 */
  text-align: center;        /* 水平居中（针对行内元素） */
}
.child {
  display: inline-block;     /* 块级元素需转为行内块 */
}
```

兼容 IE8+，但父元素需要有明确高度，且 `table-cell` 会影响布局。

### 方法 7：line-height（单行文本垂直居中）

```
.parent {
  height: 100px;
  line-height: 100px;        /* 等于高度 */
  text-align: center;        /* 水平居中 */
}
```

仅适用于**单行文本或行内元素**，多行文本会出问题。

### 方法 8：仅水平居中 — `margin: 0 auto`

```
.child {
  width: 200px;              /* 必须有确定宽度 */
  margin: 0 auto;
}
```

最经典的块级元素水平居中方法，利用 `auto`  margin 平分剩余空间。

## 面试总结

### CSS的布局有哪些?
CSS布局有:flex布局，grid布局，三栏布局，双飞翼布局，圣杯布局。

flex布局是一个一维布局模型，一次只处理一个维度（行或列）上的元素布局，分为主轴和副轴。通过设置display:flex属性将当前元素的布局设定为flex布局；除此之外，flex-direction(设置主轴方向水平还是垂直)，justify-content(主轴对齐方式),align-items(副轴对齐方式)。

grid布局是一个二维布局模型，由网格容器，网格线，轨道，网格对象，区域属性组成，通过设置容器的属性值来对容器内容进行布局。

### 进行垂直水平居中的方法

1.使用flex布局

```css
.parent {
  display: flex;
  justify-content: center;   /* 主轴居中 */
  align-items: center;       /* 交叉轴居中 */
}
```

2.使用grid布局

```css
.parent {
  display: grid;
  place-items: center;       /* align-items + justify-items 简写 */
}
```

3. line-height（单行文本垂直居中）

```css
.parent {
  height: 100px;
  line-height: 100px;        /* 等于高度 */
  text-align: center;        /* 水平居中 */
}
```
